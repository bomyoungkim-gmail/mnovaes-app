# 🎨 Diretrizes de UI/UX: Éthéré & L'Atelier

## 1. Conceito Éthéré (Joalheria de Luxo)
- **Atmosfera:** Nocturnal, High-Contrast, Celestial.
- **Cores:** Deep Navy (#050505), Champagne Gold (#D4AF37).
- **UX Key:** Foco em iluminação. O fundo escuro deve ter um leve gradiente radial que segue o cursor para simular luz sobre o metal.
- **Componente Periférico:** Viewer 3D interativo com controle de reflexo (environment map).

## 2. Conceito L'Atelier (Vestuário de Luxo)
- **Atmosfera:** Diurna, Orgânica, Editorial de Moda.
- **Cores:** Greige (#F2F0EB), Charcoal (#1A1A1A).
- **UX Key:** "Tactile Scrolling". O uso de imagens macro de tecidos que se expandem ao scroll para mostrar a trama da seda/algodão.
- **Componente Periférico:** Video-commerce. Mini-vídeos de 3s que rodam ao hover do produto.

## 3. Mobile-First (Essential)
- **Navegação:** Bottom Tab Bar para ações rápidas (Busca, Conta, Sacola).
- **Gestos:** Swipe horizontal para galerias de imagens com feedback tátil simulado visualmente.
- **Checkout:** UI simplificada para Apple Pay/Google Pay integrada no mockup.
